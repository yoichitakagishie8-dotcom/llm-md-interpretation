# Capabilities of LLMs in Interpreting MD Data

This repository contains the supplementary data for the manuscript:
**"Capabilities of Large Language Models in Interpreting Melting and Solidification Dynamics of Metal Powder from Molecular Dynamics Data"**

## Contents
- `prompts/`: Standardized system prompt provided to the LLMs.
- `responses/`: Raw full-text responses generated by all 10 foundation LLMs in a zero-shot setting.

## Data Availability
All data in this repository are freely accessible for research and benchmarking purposes.
